# Interview Learning Assistant - BYOK

Open-source learning assistant for interview preparation and technical learning.

## Features
- BYOK: Bring Your Own Key - OpenAI-compatible API support
- Detailed explanations for concepts
- Concise vs Detailed answer modes for practice
- Architecture diagram generation via Mermaid
- Quiz / test generation
- Practice Q&A mode with adaptive questioning
- Research prompt builder for deep learning
- No stealth / hidden mode - fully transparent for ethical learning

## Quick Start
1. Copy `.env.example` to `.env` and add your API key
2. `npm install`
3. `npm run dev`

## Tech Stack
React + Vite + TailwindCSS
Node.js API client for BYOK
